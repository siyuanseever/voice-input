# Example vocabulary. install.sh copies it to ~/.config/voice-input/vocab.txt; edit that copy afterwards
# (also editable in the menu bar microphone → Open Panel → Settings → Vocabulary).
#
# Two kinds of lines:
#   one term per line        → added to the prompt: "if you hear something that sounds like this, spell it this way"
#   wrong => right           → replaced after transcription, for when the model still gets it wrong
#                              (English is matched as whole words, case-insensitive)
#
# Tip: use it for a few days first, then add the terms that keep coming out wrong in your real transcripts.
# A very long list makes the model force words from it into places where you did not say them.
